المزامنة مع GitHub

كيف أحصل على المفتاح؟
  1. افتح صفحة إنشاء المفتاح في GitHub.
  2. في Token name اكتب: mawaqi، وفي Expiration اختر أطول مدة.
  3. في Repository access اختر Only select repositories ثم اختر mawaqi.
  4. في Permissions افتح Repository permissions، وعند Contents اختر Read and write.
  5. اضغط Generate token، وانسخ المفتاح والصقه هنا.

المفتاح يُحفظ في هذا المتصفح فقط، ولا يستطيع إلا تعديل مستودع mawaqi.
